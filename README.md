# 컴공생 키우기 — 최신 전체 통합본

`게임실행.cmd`를 실행하거나 VS Code Live Server로 `index.html`을 여세요. HTML 파일을 직접 더블클릭하면 Worker가 동작하지 않습니다.

## 진행과 화면
- 2026년 3월 입학, 4년·192턴. 실제 월별 일수와 윤년을 달력에 표시합니다.
- 한 달 4주 활동을 계획하고 한 주씩 실행합니다. 4주차는 22일부터 월말까지입니다.
- 학생증 이름 입력 → 수저 슬롯 → 5초 입학 장면 → 기본 화면.
- 시작 소지금 0원, 첫 학기 학비는 입학 전에 납부 완료한 상태입니다.
- 첫 주 맑음·가방 정리 고정, 이후 계절·주간 날씨·생활 자세가 바뀝니다.
- 노트북 사용과 책상에서 졸기는 별도 그림입니다. 날짜·시험·과로·체력·스트레스 등에 맞춰 대사가 바뀝니다.

## 게임 규칙
- B의 기본 활동 수치와 아이템·경제·시험·과제 계산을 유지합니다. 활동 수행 방식 식별값 연결 오류는 수정했습니다.
- 스트레스 70 이상이면 공부·알바의 양수 획득량에 0.8배를 적용합니다. 과거 제안한 확률식은 사용하지 않습니다.
- 과제는 학기 중 월말에 자동 평가합니다. 월별 성공 시 25점, 학기 최대100점. 직전 시험 요구 지능이0이거나 GPT Plus 사용 중이면 성공하며, 그 외 성공 확률은 현재 지능/직전 시험 요구 지능입니다. 공부로 별도 진행률을 채우거나 수동 제출하는 구조가 아닙니다.
- 전공 중간·기말은 각각4문제. 현재 지능이 요구치 이상이면 쉬움, 미만이면 어려움. 학기 성적은 중간40%+기말40%+과제20%입니다.
- 월말 월세60만원, 이후 학기 학비200만원에서 장학금·수저 지원을 적용합니다.
- 수저: 다이아5%(학비·월세), 금15%(월세), 은35%(학비), 흙45%(지원 없음).
- 해커톤은 매년5월·11월3주차 개최, 회차별1회 참가. 수상 기준과 상금·스탯 효과는 기존 B 계산을 사용합니다.
- 방학 자격증·토익이 같은 주에 잡히면 순서대로 모두 응시한 뒤 한 주를 완료합니다.
- 계획된7개 엔딩과 AI안경 부정행위 퇴학에 전용 장면이 있습니다. 대학원 진학을 선택하면 '진엔딩 발생!' 후 대학원 엔딩을 보여줍니다.
- AI안경은 엔딩 달성 후 다음 회차에서 해금,100만원 고정. 시험당10% 적발·퇴학 규칙을 유지합니다.

## 저장
주간 계산 완료 시 이름·계획·환경을 포함해 연출 전에 자동 저장합니다. 아이템·대회 처리와 계획 저장도 지원합니다. 시험 응시 중에는 마지막 완료 주에서 재개합니다. 불러올 때 능력치뿐 아니라 기록·아이템·환경·일정 형식도 검사합니다.

## 완성본 최종 검토 (2026-11-26)

## 화면 가독성과 군 복무 연출 (2026-11-26)
계획 창의 기본 효과를 아이콘 카드로 표시하고, 상점·결과·성장 기록·시험 등 보조 문구를 읽기 쉬운 크기와 글꼴로 조정했습니다. 기본 달력은 종이 달력 형태이며 월말의 월세 날짜·금액 또는 지원 혜택을 표시합니다.
군대 이벤트는 입대→복학 그림 연출→군 적금·능력치 변화 확인으로 이어집니다. 수동 입대와 자동 입대에 연결되며 기존 B의 계산은 유지합니다.

## 군 휴학 2년과 목봉체조 (최신 변경)
